# App Studio moved into Nebo

App Studio is built into Nebo 0.16.7 and later as the bundled `app-studio`
skill: the one skill for building any app or game, with the design method,
the gate and the build steps included. Load it with `use_skill("app-studio")`.

This marketplace copy no longer carries instructions, so it can never
disagree with the built-in one. On an older Nebo, update Nebo to get App
Studio.
